

# 🌡️ ThermoMind — Deribit Risk Thermometer

> “数据也有体温。”  
> 让风险率从数字，变成一种能被感知的呼吸。  

---

## 🧭 简介
**ThermoMind** 是一个为 [Deribit](https://www.deribit.com) 设计的 Chrome 插件脚本。  
它将账户的 **IM（Initial Margin）** 与 **MM（Maintenance Margin）** 转化为动态色温，  
让交易者能通过色彩感受风险的“体温”，而不仅仅是读数字。

这不只是一个风险监控工具，而是一种 **神经感知界面** ——  
它让交易系统与人的感知同步呼吸。

---

## 🧠 工作原理
- **IM / MM** 比值被实时读取，并归一化到 0–100%。  
- 颜色通过 *分段渐变 + 非线性映射* 生成，形成一个“有情绪的温度图谱”：  

| 区间 | 含义 | 颜色表现 |
|------|------|----------|
| ≤20% | 冷得失去生命力 | 🩶 灰 |
| 20–40% | 从冷蓝快速升温 | 💙 蓝 |
| 40–65% | 恒温绿区，呼吸顺畅 | 💚 绿 |
| 65–75% | 快速升温，开始紧张 | 🟠 橙 |
| 75–90% | 火红区，系统高压 | 🔴 红 |
| >90% | 过热衰竭，失去生命力 | 🩶 灰 |

色彩会在 Deribit 的仪表盘中平滑流动，就像系统在呼吸。  
你会“看到”自己的账户在发热或冷却。

---

## ⚙️ 安装与使用
1. 克隆仓库：
   ```bash
   git clone https://github.com/yourname/ThermoMind.git
   ```
2. 打开 Chrome → `扩展程序` → 开启 **开发者模式**  
3. 点击 “加载已解压的扩展程序”，选择 `ThermoMind` 文件夹。  
4. 打开 [Deribit Dashboard](https://www.deribit.com/dashboard)。  
5. 插件会自动在余额位置显示 IM / MM 的色温指标。

## 💬 色彩哲学
在 ThermoMind 中，**颜色不是警告，而是呼吸**。  
- 当它是柔和的绿，你与市场共振。  
- 当它偏红，是系统的高热；别急着操作，先深呼吸。  
- 当它灰暗，是能量不足的信号，该休息、冷却、重启。
